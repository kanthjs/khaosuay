# khaosuay: Knowledge-based Harvest & Agricultural Output: Statistical Unified Analysis for Yield

Tools for cleaning, analyzing, and visualizing agricultural experimental
data (RCBD) and survey data. Provides smart column mapping
(Thai/English), data quality checks, outlier detection, ANOVA with
Duncan's multiple range test, and Thai-language plot support.
