# ทำความสะอาดข้อมูลเบื้องต้น (ล้างข้าว)

ลบแถวที่มีค่า NA ออกจากข้อมูลก่อนนำไปวิเคราะห์ด้วย \[cook_rcbd()\]

## Usage

``` r
wash_rice(data)
```

## Arguments

- data:

  data.frame ที่ต้องการทำความสะอาด

## Value

data.frame ที่ลบแถวที่มี NA ออกแล้ว

## Examples

``` r
df <- data.frame(x = c(1, 2, NA, 4), y = c("a", "b", "c", NA))
wash_rice(df)
#> ทำความสะอาดเมล็ดข้าวเรียบร้อย: ลบข้อมูลที่ไม่สมบูรณ์ออกแล้ว
#>   x y
#> 1 1 a
#> 2 2 b
```
